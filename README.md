# Vivek Kumar academic website — version 2

This version intentionally embeds the CSS inside every HTML file so GitHub Pages does not depend on an `assets/css` folder. This fixes the unstyled-page problem visible in your screenshot.

## Upload
1. Open your `VivekTrpt.github.io` repository.
2. Delete the old website files (or replace them).
3. Upload every `.html` file from this folder to the repository root.
4. Commit changes.
5. GitHub Pages will redeploy automatically.

Your site remains free at `https://VivekTrpt.github.io`.
